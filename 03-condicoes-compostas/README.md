# 📘 Etapa 03 — Condições Compostas

Esta pasta reúne os **exercícios 26 a 37** da lista de Algoritmos e Lógica de Programação do professor Gustavo Guanabara, do Curso em Vídeo.

Como parte da minha revisão dos fundamentos de programação, resolvo cada exercício primeiro no **VisualG (Portugol)** e depois desenvolvo a mesma solução em **Python**.

## 🎯 Objetivo da etapa

Aprofundar o estudo das estruturas condicionais, desenvolvendo algoritmos capazes de escolher entre diferentes caminhos de execução.

Nesta etapa, pratico conceitos como:

* Estruturas condicionais compostas;
* Tomada de decisões com `SE` e `SENAO` no VisualG;
* Utilização de `if` e `else` no Python;
* Operadores relacionais e lógicos;
* Comparação de valores e avaliação de condições;
* Organização de diferentes caminhos de execução;
* Aplicação de cálculos conforme as condições estabelecidas.

## 📂 Organização dos arquivos

Cada exercício possui duas versões, identificadas pelo mesmo número:

| Arquivo           | Descrição                                   |
| ----------------- | ------------------------------------------- |
| `exercicio26.alg` | Solução desenvolvida no VisualG (Portugol). |
| `exercicio26.py`  | Solução desenvolvida em Python.             |

Esse padrão é seguido até o exercício 37.

## 🛠️ Ferramentas utilizadas

* **VisualG:** desenvolvimento dos algoritmos em Portugol.
* **Python:** implementação dos mesmos exercícios em uma linguagem de programação.

## 📊 Progresso

**Exercícios:** 26 ao 37

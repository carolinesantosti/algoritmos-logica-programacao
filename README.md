# 🧠 Algoritmos e Lógica de Programação

Este repositório reúne minha prática de **Algoritmos e Lógica de Programação**, baseada nos exercícios desenvolvidos pelo professor **Gustavo Guanabara**, do [Curso em Vídeo](https://www.cursoemvideo.com/).

Como parte da minha revisão dos fundamentos de programação, decidi reassistir às aulas e resolver os exercícios em duas etapas: primeiro no **VisualG**, utilizando Portugol, e depois em **Python**.

A proposta é reforçar meu raciocínio lógico, compreender melhor a construção dos algoritmos e observar como a mesma solução pode ser implementada em linguagens diferentes.

## 🎯 Objetivos

* Revisar e consolidar os fundamentos de algoritmos.
* Desenvolver o raciocínio lógico por meio da prática.
* Compreender a construção de soluções em Portugol.
* Aplicar os mesmos conceitos em Python.
* Registrar minha evolução e organizar meus exercícios no GitHub.

## 💻 Como os exercícios são desenvolvidos

Minha metodologia de estudo segue esta sequência:

**1. Revisão:** assisto às aulas de Algoritmos e Lógica de Programação do Curso em Vídeo.

**2. VisualG:** resolvo o exercício utilizando Portugol para estruturar o raciocínio lógico.

**3. Python:** desenvolvo a mesma solução em Python, adaptando a sintaxe e aplicando os conceitos estudados.

**4. Documentação:** organizo os arquivos neste repositório para acompanhar meu progresso.

Os arquivos são identificados pelo número do exercício, facilitando a comparação entre as duas versões:

```text
exercicio01.alg  → VisualG (Portugol)
exercicio01.py   → Python
```

# 📘 Etapa 02 — Condições Básicas

Esta pasta reúne os **exercícios 17 a 25** da lista de Algoritmos e Lógica de Programação do professor Gustavo Guanabara, do Curso em Vídeo.

Como parte da minha revisão dos fundamentos de programação, resolvo cada exercício primeiro no **VisualG (Portugol)** e depois desenvolvo a mesma solução em **Python**.

## 🎯 Objetivo da etapa

Praticar a utilização de estruturas condicionais para criar algoritmos capazes de tomar decisões com base em determinadas condições.

Nesta etapa, o foco está em conceitos como:

* Operadores relacionais;
* Comparações entre valores;
* Expressões lógicas;
* Estruturas condicionais;
* Tomada de decisões com `SE` no VisualG e `if` no Python;
* Organização das instruções conforme o resultado de uma condição.

## 📂 Organização dos arquivos

Cada exercício possui duas versões, identificadas pelo mesmo número:

| Arquivo           | Descrição                                   |
| ----------------- | ------------------------------------------- |
| `exercicio17.alg` | Solução desenvolvida no VisualG (Portugol). |
| `exercicio17.py`  | Solução desenvolvida em Python.             |

Esse padrão é seguido até o exercício 25.

## 🛠️ Ferramentas utilizadas

* **VisualG:** desenvolvimento dos algoritmos em Portugol.
* **Python:** implementação dos mesmos exercícios em uma linguagem de programação.

## 📊 Progresso

**Exercícios:** 17 ao 25

**Total:** 9 exercícios, com versões em VisualG e Python.
